# 3D Model Assets for FluidGlass

Place your `.glb` 3D model files in this directory for the `<FluidGlass />` component:

- `lens.glb` (Used for Lens mode)
- `bar.glb` (Used for Bar mode)
- `cube.glb` (Used for Cube mode)

Refer to React Bits documentation for instructions on custom 3D mesh models and transmission materials.
